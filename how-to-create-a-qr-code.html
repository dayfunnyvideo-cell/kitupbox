How to Create a QR Code for Free (Complete Guide)

3 min read · Nov 13, 2026

A QR code lets someone open a link or read a line of text by pointing a phone camera at a square of black and white dots. You see them on menus, posters, receipts and business cards. Making one takes a minute, and a few simple choices decide whether it scans every time.

What a QR code can hold

  • A website link, which is the most common use
  • Plain text, such as a short message or a code
  • A phone number or an email address
  • Wi-Fi network details, so guests can join without typing a password
  • A contact card with a name, phone number and email

How to create a QR code in four steps

  1. Decide what the code should open, and check that the link works on your phone.
  2. Open the KitUpBox QR Generator.
  3. Type or paste your link or text and generate the code.
  4. Test the code with at least two different phones before you use it.

Tips so it scans every time

  • Keep strong contrast. A dark code on a light background is the safest choice. Pale colors and busy backgrounds make scanning harder.
  • Leave a clear border. Empty space around the code helps the camera find its edges.
  • Make it big enough. A code printed about 2 cm (0.8 inch) wide works for close scanning. A common rule of thumb is that a code can be scanned from about ten times its width away, so a sign read from 2 meters away needs a code roughly 20 cm wide.
  • Use a short link. Fewer characters create a simpler pattern that is easier to read.
  • Do not stretch or distort it. Keep the code square and flat. Curved or shiny surfaces can cause glare.

Static and dynamic codes

A static code stores the link or text directly in the pattern. It never expires, but you cannot change it after you create it. A dynamic code points to a redirect run by a service, so you can change the destination and track scans, but it usually costs money and stops working if the service ends. Free generators usually create static codes, so double-check your link before you print anything.

Where to use QR codes

  • Restaurant menus and table cards
  • Flyers, posters and event signs
  • Business cards that link to a website or profile
  • Product packaging that links to instructions
  • Wi-Fi sharing at home or in a small business

Stay safe with QR codes

  • Scan only codes from sources you trust.
  • Read the link your phone shows before you open it.
  • Be careful with stickers placed over another code in a public place. Scammers sometimes cover real codes with fake ones.
  • If you display a code in a public place, check it now and then to make sure nobody has covered it.

Common mistakes

  • Not testing. A code that looks fine on screen can fail on paper.
  • Printing it too small. Tiny codes are hard to scan, especially on a crowded page.
  • Forgetting https://. Include the full address so the phone opens the right page.
  • Linking to a page that is hard to use on a phone. Most people will scan with a phone, so check the page there.
  • Adding long tracking parameters. They make the pattern denser and harder to read.

Frequently asked questions

How do I scan a QR code?

Open your phone's camera app and point it at the code. Tap the banner that appears to open the link. Most current iPhone and Android phones scan codes without a separate app.

Do QR codes expire?

A static code does not expire. The page it points to can disappear, though, so keep that page live for as long as the code is in use.

What size should a QR code be?

For close-up use, such as a business card or a menu, aim for at least about 2 cm wide. Make it larger if people will scan it from farther away.
