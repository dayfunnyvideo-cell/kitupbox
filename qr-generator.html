📖 What is a QR code?

A QR code (Quick Response code) is a square pattern that stores information, such as a web address, some text, an email or Wi-Fi details. When you point a phone camera at it, the phone reads the pattern and offers to open the link or use the information. You can see them on menus, posters, packages, business cards and Wi-Fi signs.

This generator makes the QR code in your browser. The text you enter is not sent to our server.

How to make a QR code

  1. Choose what the code should do: open a website link, show text, start an email, call a phone number or join a Wi-Fi network.
  2. Fill in the details. For a website, type or paste the link.
  3. Pick an image size. Choose Large if you plan to print it.
  4. Press Generate QR Code, then Download QR (PNG).
  5. Scan it with your phone to test it before you share or print it.

✨ What you can store in a QR code

  • Website link: opens a page when scanned. If you leave out "https://", this tool adds it for you.
  • Plain text: shows a short message or note.
  • Email: opens a new email to the address you set, with an optional subject.
  • Phone number: offers to call the number.
  • Wi-Fi network: lets people join your network without typing the password. Share this code only with people you trust, because anyone who scans it can join.

🖨️ Tips for a QR code that scans well

  • Keep it dark on light. Black on white works best. Do not invert the colors.
  • Leave a white border around the code. The downloaded image already includes one, so do not crop it.
  • Print it big enough. As a common rule of thumb, the code should be about one tenth as wide as the distance people scan from. A code on a business card can be small, but a poster needs a large one.
  • Use short text. Shorter links make a simpler pattern that is easier to scan. A short link is better than a long one with many extra parts.
  • Test before you print. Scan the code with two different phones.

🔒 Static codes and staying safe

The codes made here are static. They hold the information itself, so they do not expire and do not depend on our site. The downside is that you cannot change where a printed code points. If the link might change, set up a redirect on your own website and put that link in the code.

Be careful with codes you did not make. A QR code can lead to a fake page, so check the web address your phone shows before you open it or type in any details.

❓ Frequently Asked Questions

Do QR codes made here expire?
No. These are static codes. The information is stored in the pattern itself, so they keep working as long as the link or information inside is still valid.
How do I scan a QR code?
Open your phone camera, point it at the code and tap the link or notification that appears. If your camera does not do it, use a QR scanner app.
How do I make a QR code for my Wi-Fi?
Choose Wi-Fi network, enter the network name, the security type and the password, then generate the code. People who scan it can join without typing the password.
Can I change the color of the QR code?
Not at the moment. The codes are black on white because that scans most reliably.
Is there a limit on the length?
Yes. A QR code can hold only so much. This tool uses a strong error correction setting, which allows roughly 1,200 characters of plain text, and it lowers the setting automatically for longer text. Short text gives a cleaner code that is easier to scan.
Can I use these QR codes for business?
Yes. The codes you make are yours to use, including on products, menus and flyers. Test them before you print a large run.
What is the difference between static and dynamic QR codes?
A static code holds the information inside it and cannot be changed after you print it. A dynamic code holds a short link that can be redirected later, and it usually needs a paid service. This tool makes static codes.
Is my text saved?
No. The code is made in your browser, and this page does not save what you enter.
